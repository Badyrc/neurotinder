Спасибо, что решили принять участие в нашем исследовании!

Мы изучаем поведение людей в дейтинговых сервисах, результаты исследования могут использоваться для разработки приложений для дейтинга с использованием нейросетей, корректирующей демонстрацию анкет, основываясь на выборах человека.

Вам предстоит выбрать партнера для встречи. Для этого оцените привлекательность человека на фото при помощи клавиш 1-7 и ответьте на вопрос «У Вас есть желание познакомиться с этим человеком?» (нет - 1 или да - 2).

Настройка исследования

На GitHub Pages имена файлов в открытом репозитории определяются автоматически. Фотографии должны находиться в папке faces рядом с Index.html. Схема папок приведена в README.md.

Для работы без автоматического поиска выберите всю папку faces. Каталог с именами файлов будет встроен в HTML. Содержимое фотографий в HTML не встраивается.

Опубликуйте поставляемый Code.gs и вставьте адрес /exec. Основная версия использует сервер для чередования блоков и сохранения ответов. Тестовые версии не обращаются к таблице.

Если каталог недоступен, проверяются файлы 001.jpg, 002.jpg и далее. Отсутствующие фотографии заменяются пронумерованными заглушками и помечаются в данных.
